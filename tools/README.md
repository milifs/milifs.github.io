# Fuentes de imagen

Plantillas HTML para regenerar las imágenes de `assets/`. No forman parte del sitio.

- `og-card.html` → `assets/og.jpg` (1200×630, preview al compartir el link)
- `icon-card.html` → `assets/apple-touch-icon.png` (180×180)

Para regenerarlas: levantar el servidor local, abrir el archivo en el navegador
con la ventana en el tamaño exacto, capturar y guardar en `assets/`.
